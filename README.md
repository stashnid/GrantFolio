# GrantFolio

GrantFolio — асистент для підготовки бізнесу до грантового фінансування. Локальна тестова версія підтримує реєстрацію/вхід, профіль бізнесу, приватні проєкти, опис клієнтів і плану реалізації, бюджет, перевірку заповненості та експорт робочої чернетки TXT або друк у PDF, відновлення пароля і добровільні відгуки. Дані зберігаються в PostgreSQL.

Пілотна програма — «Власна справа», вибір користувача. Відкритий раунд і чинну офіційну форму ще не підтверджено; картка веде до першоджерела. Перевірка заповненості не визначає відповідність програмі. Асистент може відповідати через прямий серверний Gemini API; потрібен окремо налаштований ключ. OmniRoute використовується для розробки в Codex і не є залежністю застосунку. HTTPS deployment і публічний URL ще відсутні.

[Повне бачення продукту](docs/product-vision.md) описує цільові можливості; реалізований обсяг наведено вище.

## Локальний запуск

Потрібні Node.js 24, npm та запущений Docker з Compose. Команди виконуються з кореня репозиторію. Auth Emulator створює тільки локальні тестові акаунти; PostgreSQL використовує локальний Docker volume.

```sh
cp .env.example .env
npm ci
docker compose up -d --build
npm run migrate
npm run dev
```

Відкрийте http://localhost:5173. Зареєструйтеся з тестовим email і паролем, заповніть профіль і відкрийте «Мої плани»: створіть чернетку, заповніть опис проєкту, клієнтів, канали продажу, план реалізації та очікувані результати. Збережіть опис, додайте витрати й збережіть бюджет. Перевірте список збережених даних і завантажте робочу чернетку TXT. Експорт містить збережену версію та позначає відсутні поля; це матеріал для підготовки, не офіційна заявка. Ціна вводиться у гривнях з не більше ніж двома знаками після коми; сервер розраховує підсумок у цілих копійках. Оновіть сторінку або вийдіть і увійдіть знову. Якщо бюджет змінився в іншій вкладці, форма зберігає ваші незаписані зміни для копіювання до завантаження актуальної версії. `.env` містить локальні налаштування та може містити серверний ключ Gemini; файл ігнорується Git. Не передавайте його іншому учаснику й не додавайте до Git. Emulator і база доступні лише через loopback хоста. Для зупинки сервісів: `docker compose down`. Volume з профілями зберігається.

```sh
npm run typecheck
npm run build
npm test
```

Інтеграційний тест потребує запущених emulator та PostgreSQL, виконаної міграції й `.env`; він створює два тестові акаунти та перевіряє ізоляцію профілів і чернеток, некоректні токени, арифметичні межі, конкурентні зміни та повтори команд бюджету. Акаунти emulator тимчасові, профілі у volume зберігаються.

## Production image

`Dockerfile` збирає frontend і API в одному образі. Для майбутнього production build необхідно передати `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, `VITE_FIREBASE_PROJECT_ID`, `VITE_FIREBASE_APP_ID` як build arguments; це публічна конфігурація Firebase, не секрети. Runtime потребує `FIREBASE_PROJECT_ID`, `DATABASE_URL` та налаштованих Application Default Credentials. Emulator заборонений у production. Міграцію потрібно виконувати окремим процесом з цього образу командою `npm run migrate:prod` перед запуском; готового deployment або cloud resources наразі немає. Потрібні HTTPS, Firebase email/password, реальні домени та окрема перевірка перед публічним використанням.

## Асистент

Для відповідей задайте серверні `GEMINI_API_KEY` і `GEMINI_MODEL=gemini-3.5-flash-lite` у приватному `.env` та перезапустіть API. Ключ не має префікса `VITE_`, не потрапляє у браузер і не передається через OmniRoute. Без ключа генерація повертає 503, історія доступна. Перед використанням перевірте Free Tier свого API-проєкту; назва моделі не гарантує безкоштовний тариф. Платний резерв не налаштований.

Відповіді спираються на збережену версію справи; після змін попередні відповіді позначаються застарілими. Асистент не здійснює живий пошук і не визначає право на грант. Каталог містить довідкові програми з датою перевірки та статусом прийому. Вибір довідкової програми наразі діє лише в поточному сеансі інтерфейсу.

## Відгуки та розгортання

Після входу доступна добровільна форма «Залишити відгук». Відгуки зберігаються приватно, повтор відправлення не створює дубліката. Технічні перевірки не вважаються відгуками реальних користувачів. Для завдання викладача потрібні справжній пілот і фактичний звіт PDF.

[Google Cloud runbook](infra/README.md) містить кроки підготовки й розгортання. Публічне HTTPS-демо ще не розгорнуто: Google Cloud-проєкт та авторизовані доступи відсутні. [Codex через OmniRoute](docs/omniroute-setup.md) налаштовується окремо від продукту.
