Конфіденційність

GrantFolio допомагає знаходити фінансування для бізнесу й готувати чернетки грантових заявок.

Вхід та акаунт

Firebase Authentication обробляє вхід через Google або через електронну пошту й пароль. Для входу через Google застосунок отримує базову інформацію про акаунт, зокрема адресу електронної пошти та ідентифікатор. GrantFolio використовує ідентифікатор для перевірки доступу до вашого кабінету. Для входу з паролем застосунок може надсилати одноразовий код на адресу, яку ви вказали.

Дані в кабінеті

У Google Cloud зберігаються дані, які ви додаєте до профілю, проєктів, бюджетів, чату чи відгуків. Вони потрібні для збереження вашої роботи, відображення попередніх розмов і підготовки чернеток. Доступ до приватних проєктів перевіряється за акаунтом.

Коли доступний AI-асистент, запит і пов’язаний з ним контекст можуть передаватися Gemini для формування відповіді. Користувацький вхід через Google використовується для авторизації. Окремий дозвіл Gmail акаунта підтримки застосунок використовує для надсилання кодів підтвердження.

Запити щодо даних

Ви можете видаляти свої проєкти в кабінеті. Щодо даних акаунта, виправлення або видалення напишіть на grantfoliomanager@gmail.com.
