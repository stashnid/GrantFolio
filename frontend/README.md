# Frontend

Поки містить лише план; інтерфейс і команди запуску ще не створено.

План: React/Vite/TypeScript, Firebase Auth Web SDK, серверний `/api`. Основні розділи: Асистент, Можливості, Мої заявки, Мій бізнес. У production зібраний frontend обслуговується Cloud Run web на одному origin з API.

Перший зріз — реєстрація, вхід, вихід і повернення до власного профілю після reload. Довгі операції відображають збережений job status. [Архітектура](../docs/architecture.md), [backlog](../docs/BACKLOG.md).
