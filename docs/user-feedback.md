# Фактичні користувацькі відгуки

Поки користувацьких тестів не проводили. Це робочий шаблон для майбутнього PDF, не звіт про виконані дії.

Для кожної сесії записати дату/версію демо, анонімний participant ID, релевантну роль, який сценарій людина справді спробувала, спостереження/дозволену цитату, запропоновану зміну і посилання на її реалізацію/перевірку. Кількість учасників рахувати за людьми, а не повідомленнями.

У підсумковому PDF відповісти саме на завдання: кому показали, скільки людей спробували, що сказали та що змінили. Не додавати вигадані цитати чи непроведені дослідження. Оплату/пожертву включати лише якщо вона відбулася й є дозволений доказ; це бонус.

Контакти, приватні документи та неанонімізовані нотатки залишаються поза Git. Користувацький відгук не дозволяє автоматично використати заявку для навчання моделі.
