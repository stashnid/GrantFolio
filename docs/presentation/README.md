# GrantFolio: презентація Module 11

Актуальна виправлена версія після звірки широти продукту з кодом, документацією та рішеннями в інших чатах проєкту. **7 основних слайдів на 5 хвилин, включно зі 100 секундами живого демо.** Слайди 8–9 — додатки.

- [PDF для подання](GrantFolio.pdf)
- [Редагована презентація](GrantFolio.pptx)
- [Сценарій виступу, демо та відповіді](speaker-notes.md)
- [Підстава кожного суттєвого твердження](facts.md)
- [Вихідний зміст](slides.json) і [побудова](build-slides.mjs)

Критерії: 5 хвилин, біль і проблема, конкуренти та унікальна цінність, live demo. Враховано особисті запитання викладача про разову оплату, навчальні підказки, організації як можливого платника й розмір ринку. Окремого слайда відгуків немає.

Показано 97 підключених записів українських і міжнародних програм та можливостей підтримки. Це різні типи фінансування та різні статуси прийому. «Власна справа» — приклад демо підготовки, а не весь каталог. Підтверджених покупок 0. Вилучено непогоджені цілі пілоту й довільні суми витрат. Фактичної собівартості для розрахунку точки беззбитковості ще немає.

Презентація створена у live Artifact Session, PDF отримано з PPTX через LibreOffice та перевірено візуально. Перед виступом потрібно провести репетицію точного live-шляху на поточній версії сайту. Приватний зданий звіт і повні історії чатів до Git не копіюються.
