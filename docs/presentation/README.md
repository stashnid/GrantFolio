Мова — українська. Звіт з попереднього завдання не є окремим слайдом: критерії цього виступу — 5 хвилин, проблема, конкуренти й унікальна цінність, живе демо. Коментарі викладача щодо ринку, монетизації, даних та економіки враховано.

Суми 1 500 грн на місяць і 2 грн на проєкт — сценарні припущення, **не фактичні витрати**. Реальні витрати й комерційний тариф треба перевірити. 5 грн — поточна пілотна ціна. Цілі на останньому слайді — пропозиція для наступного пілоту, **не досягнуті результати**.

Слайди створені у live Artifact Session з українськими примітками. PDF конвертовано з експортованого PPTX через LibreOffice через недоступну реєстрацію PDF-шрифтів у live-сесії. Після конвертації PDF перевірено окремо. Завантажуваний користувачем звіт із тестуванням не копіюється до Git.
