# KVED-2010 class directory

The bundled `frontend/src/data/kved-2010.json` contains the Ukrainian class titles published in the [Ukrstat KVED-2010 index](https://kved.ukrstat.gov.ua/KVED2010/kv10_i.html). Each entry has a class code (`value`), official title (`label`), section letter and official class-page URL (`source`). Titles are taken from the class rows of official group pages; the source points to the linked class page.

On 2026-11-15 UTC the crawl processed all 21 linked sections, 88 linked divisions, and 272 linked groups, yielding 615 distinct class rows with zero failed pages. The labels and links for 23.41, 56.10, 62.01 and 47.91 were also checked against their individual official pages. Counts describe this retrieval and are not fixed assumptions about future versions.

To refresh, run `python3 scripts/update-kved-directory.py` with internet access. The script follows the official index hierarchy with at most four concurrent requests, a 30-second timeout and two retries per request. It caches the downloaded public HTML in `/private/tmp/grantfolio-kved-2010` and always downloads fresh pages. It rejects missing child rows, invalid links, mismatched parent codes and duplicate entries, and writes the JSON atomically only after the complete crawl succeeds. A failed crawl exits nonzero and leaves the existing dataset unchanged. Review the reported counts and resulting changes before committing.
