# Передача роботи: планування 12.11.2026

## Результат

Google Cloud обраний користувачем. Поточна пропозиція — TypeScript modular monolith, Cloud Run web/private worker, Firebase Auth, Cloud SQL і private Storage. Деталі — в [архітектурі](../architecture.md). Попередній AI-кандидат і обмеження — в [дослідженні](../ai-model-research.md); матеріалів для навчання немає.

База до документації: main `74b9bdd6c367c79a7233375feb56904a1d62860c`, перевірена свіжим fetch. Поточний коміт і нові гілки обов'язково перевірити при відновленні.

## Перші дії наступної сесії

1. Прочитати AGENTS і STATUS, перевірити локальні зміни та свіжий origin. Не перезаписувати роботу друга.
2. Обрати B01/B02/B03, створити task branch, записати власника й файли у звіт агента.
3. Зафіксувати першу програму та офіційну форму. Не вигадувати демонстраційні правила під назвою чинного гранту.
4. Перевірити конкретний GCP project, права, billing і модельний доступ. Для фактичного розгортання/платного пілота визначити ресурси й кошторис; сьогодні їх не створювали.
5. Почати з HTTPS sign-up/sign-in та захищеного API; додавати реальні інструкції запуску одночасно з кодом.

Паралельно можна готувати дозволені навчальні приклади. Не запускати SFT на неперевірених відповідях заради самого факту навчання.
