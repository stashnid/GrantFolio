## Реалізовано в повному обсязі

- **Автентифікація та профілі**: React/TypeScript + Express 5, PostgreSQL 17, Firebase Auth Emulator (та Cloud Firebase Auth для production); реєстрація, вхід, вихід, збереження профілю та відновлення пароля.
- **Приватні справи та покроковий майстер (Wizard)**: покроковий опис, цільова аудиторія, план реалізації, точний бюджет у цілих копійках, захист незбережених змін, конкурентних правок і повторів команд, каскадне видалення чернеток; інтегровано візуальний трекер прогресу готовності проєкту (у відсотках та з позначками `✓`), динамічний смуговий індикатор використання бюджету відносно ліміту обраної програми, картковий дашборд справ та двонаправлену навігацію між кроками.
- **Преміальний дизайн-код та інтерфейс**: глибока смарагдова палітра (`#183e2b`, `#24573e`), скляний напівпрозорий хедер із розмиттям фону (`backdrop-filter: blur(14px)`), багаторівневі м'які тіні, поліровані поля вводу, картки та плавні переходи станів.
- **Персистентна прив'язка програми (`program_id`)**: вибір програми зберігається в PostgreSQL для кожної справи (міграція 007); адаптивні ліміти бюджету (250 тис. / 1 млн / 8 млн / 10 млн грн) та адаптивні шаблони витрат під конкретну програму; відображення програми у TXT-експорті та друкованому PDF.
- **Проактивний асистент (Gemini API)**: прямий серверний виклик Gemini 3.5 Flash-Lite з інжекцією правил цільової програми та джерел (`grantSourceContext`); асистент самостійно бере ініціативу, пропонує ринкові ціни для обраної ніші та ставить зустрічні запитання для ведення діалогу; автоматичне виявлення позицій та перенесення в бюджет в 1 клік з попереднім переглядом позицій у вигляді чіпів; збережена історія діалогів та маркування застарілих відповідей (`stale`).
- **Каталог грантових програм**: порівняння офіційних програм (Власна справа, Ветерани, Переробка, Агро) з пошуком, фільтрами та кнопкою «Приміряти грант».
- **Експорт у форматі для Дії та PDF**: завантаження робочої TXT-чернетки для заповнення форми на diia.gov.ua та функція «Зберегти як PDF / Друк» через чисті стилі `@media print`.
- **Добровільні відгуки користувачів**: оцінка від 1 до 5 зірок, категорія вражень, коментар, збереження в PostgreSQL без дублікатів (міграція 006).
- **Модуль солідарності та готовності платити (Assignment Bonus)**: прямі посилання на БФ «Повернись живим», спецрахунок НБУ для ЗСУ, фонд Притули та підтримку розробки; фіксація внесків у PostgreSQL (міграція 008, `/api/donations`) та публічний лічильник.
- **Офіційний звіт про користувацьке тестування (PDF)**: підготовлено детальний документ [docs/user-testing-report.md](user-testing-report.md) та згенеровано публікаційний файл [docs/user-testing-report.pdf](user-testing-report.pdf) (538 КБ, 5 респондентів, цитати, зміни, докази донатів на 950 грн).
