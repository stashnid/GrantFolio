# Поточний стан GrantFolio

Оновлено: 13 листопада 2026. Стан після підготовки спільного плану; автор змін — координатор Codex із висновками трьох агентів.

## Що вже є

- Приватний репозиторій `stashnid/GrantFolio`, опис продукту в README.
- Обрано Google Cloud; створено поточний архітектурний план, дослідження моделей і план донавчання.
- Реалізовано локальний React/Express зріз: Firebase Emulator auth, PostgreSQL-профіль, owner-scoped API, Compose, Dockerfile та тести. Браузерна перевірка реєстрації, збереження, reload, виходу й повторного входу пройшла; див. [звіт R0/R1](agents/2026-11-13-local-auth-coordination.md).
- Є правила роботи агентів, журнал рішень, задачі, звіти й передача роботи. Історичні варіанти збережено окремо.
- Перед зведенням перевірено свіжий origin: main = `74b9bdd6c367c79a7233375feb56904a1d62860c`; нових командних комітів тоді не було. Коміт цієї документації див. у Git log; актуальну віддалену версію перевіряти заново кожної сесії.

- Додано локальні чернетки плану й бюджет UAH: owner-scoped справи, точні суми, revision/conflict/idempotency та історія бюджету в SQL. Браузером перевірено створення, зміну ціни й повернення після reload. [R2](agents/2026-11-13-case-budget-coordination.md).

## Що ще не зроблено

Немає production HTTPS deployment, URL демо, підтримки офіційної грантової програми, модельних викликів, навчального набору, донавченої моделі чи результатів користувацького тестування. Локальний код auth/profile створений; його готовність відрізняємо від розгорнутого продукту. Звіту PDF із реальними відгуками ще немає. Перевірка документації не є перевіркою працездатності продукту.
