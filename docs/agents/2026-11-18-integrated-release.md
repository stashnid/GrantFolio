## Результат інтеграції

- Очищений зразок Дії і робочий експорт XLSX/PDF з коміту `278ddde`. Переносяться вісім зіставлених відповідей. Прийняття файлів порталом Дії ще не перевірене.
- Анкети й фінансовий план з PR №17 разом із самостійним сценарієм та навчальними підказками з PR №19.
- Панель моніторингу, відкриття джерел і правила верифікації з поточної `main`. Для «Власної справи» відкритий прийом підтверджує лише звірка календаря зі сторінкою послуги. Модельна пропозиція або ручне погодження пропозиції окремо не відкриває прийом.
- PDF має A4, номер версії, джерела й позначку робочої чернетки. Друк використовує підтверджені збережені дані, збережено окремі TXT та фінансовий XLSX/PDF.
- Тестовий лист може йти лише на підтверджену адресу акаунта. PostgreSQL обмежує частоту і зберігає обмеження між екземплярами сервера. Ліміт звернень до Gemini у чаті проєкту також спільний між екземплярами.

Репозиторні інструкції з попередніх гілок і старі варіанти інтерфейсу зберігаються у своїй історії. Старий варіант ключів повторної зміни програми потребує узгоджених змін клієнта і сервера. Історичний PDF зі спірними твердженнями залишився заміненим звітом про наявні докази.

## Верифікація і розгортання

Міграції перевіряються на окремій PostgreSQL, застосовуються за повними назвами файлів. У першому прогоні модульний тест парсера отримав 500, оскільки його SQL-імітація не реалізує новий ліміт. Для цього тесту передається контрольований ліміт, а справжній міжсерверний допуск перевіряють окремі інтеграційні тести.

Реліз відбувається через чинний GitHub Actions після інтеграції в `main`. Локальний gcloud потребував повторного входу. GitHub Actions використовує вже налаштовану федерацію ідентичності. Виконання перевіряється за SHA. Діючий workflow застосовує міграції, розгортає ревізію, переключає трафік і звіряє публічний health.

Другий прогін пройшов 172/172 тести, перевірку типів, збірку й перевірку diff. Chromium відрендерив друк A4 на синтетичній чернетці з 47 бюджетними позиціями, п’ятьма сторінками і шістьма офіційними HTTPS-посиланнями. Це перевірка друку зі збережених даних.

Після додавання опублікованої гілки шаблону Дії пройшли 180/180 локальних тестів з LibreOffice, перевірка типів і збірка. Автоматична перевірка дозволів зупинила злиття до `main`, оскільки воно запускає виробниче розгортання. Публічний сайт продовжує працювати на попередній ревізії.

Перший CI-прогін із шаблоном Дії завершився на `spawn soffice ENOENT`. Етап перевірки GitHub Actions тепер установлює LibreOffice Calc і шрифти та запускає тести конвертації для обох робочих експортів. Кроки виробничого розгортання збережені.
