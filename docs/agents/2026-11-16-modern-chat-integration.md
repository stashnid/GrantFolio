## Реалізація

Native select розмов замінений історією в єдиній бічній панелі застосунку: активний чат, пошук назв, нова розмова, позначення ненадісланого тексту, прокручування довгого списку. На мобільному — drawer з Escape/focus trap/поверненням фокусу. Перехід від потреби в каталозі або від проєкту відкриває окрему розмову без автоматичного надсилання й зберігає попередню чернетку; зайняту розмову перехід дочікується.

Шрифт Manrope з українськими/латинськими символами розміщений локально разом із SIL OFL. Відомості й джерело: [локальний font README](../../frontend/public/fonts/README.md), [офіційна сторінка](https://fonts.google.com/specimen/Manrope), [upstream ліцензія](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt). Runtime-запитів до Google Fonts немає. Навігація отримала узгоджені іконки, відступи й стани. Відповіді мають обмежену ширину, 16px текст, абзаци, безпечні заголовки, нумеровані/марковані списки й виділення, без виконання HTML.

Ручне створення проєкту потребує назви; опис ідеї необов'язковий. `programId: string | null`; відсутній/явний null при POST означає null, без мовчазної «Власної справи». Наявні прив'язки збережені. Нейтральні підказки, бюджет, readiness, контекст моделі й TXT/друк не підставляють грантових лімітів або вимог. Програма з конкретної рекомендації зберігається як явний вибір.

Із наявного проєкту «Підібрати фінансування» відкриває окрему розмову. Повернення з рекомендацією показує підтвердження для того самого project ID: новий case не створюється. Dirty/recovery/pending/conflict і revision контролюються, застаріла прив'язка не перезаписує дані. Перед створенням/прив'язкою UI повторно перевіряє поточний запис програми, а не знімок старої картки.

Каталог має одне поле пошуку й явну кнопку, очистку, початкові підказки й фокус результатів за Enter. При введеному запиті зайві початкові блоки не відсувають результати вниз. Пошук індексує назви/донорів, витрати, заявників, умови й документи, використовує синоніми, варіанти написання та помилкову клавіатурну розкладку. Збережені sourced мапінги для комерційного транспорту, молодіжного бізнесу й відшкодування. Особисте авто/освітні стипендії не підміняються бізнесовою допомогою; виключення не є позитивною підставою. Завершені/непідтверджені можливості не додаються. Старий дедлайн при неактуальному підтвердженні названий останнім відомим.

Донати вилучені з навігації, набору відкриваних вкладок та монтування компонента; попередній remembered-tab donations переходить до асистента. Серверні записи/історичні дані внесків не видалялися.
