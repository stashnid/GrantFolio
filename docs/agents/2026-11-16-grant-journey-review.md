## Хід роботи і рішення

Деталі відкриваються в застосунку з hash, пошук і фільтр зберігаються у змонтованому каталозі. Синхронізація вибраної програми повторюється при поверненні на вкладку, оскільки `replaceState` не створює `hashchange`. Слухач і переміщення фокуса працюють лише у видимому каталозі; заголовок деталей отримує фокус, повернення відновлює фокус картки за наявності. Невідомий ID має повідомлення та посилання назад. Статус відкритого прийому має власний підпис. CSS скидає глобальне оформлення `header` для заголовків каталогу. Біля Cases додано нагадування, що асистент використовує збережені дані профілю.
