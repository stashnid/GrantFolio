# OmniRoute перенесено до Codex

Завдання користувача: прибрати помилкову інтеграцію з GrantFolio, використати шлюз для розробки в Codex. Координатор: gpt-6.1-sol; видалення інтеграції делеговано gpt-6.1-terra. Гілка feat/test-version-preparation, base 94acc4b; перед змінами local status чистий, fresh ls-remote підтвердив збіг гілки та актуальні голови інших гілок.

## Зміни

- Terra видалив серверний gateway adapter та параметри запуску; історія/інтерфейс асистента збережені, нові відповіді 503. Типи, build, 12 тестів і shell syntax PASS.
- Координатор перемістив весь .local/model-gateways за межі репозиторію у ~/.codex/omniroute. Секрети лишилися приватними. Продуктовий assistant.env вилучено.
- Зареєстровано model_providers.omniroute, default model codex-free у користувацькій конфігурації Codex, з приватною резервною копією попередньої конфігурації. Секретний локальний endpoint key збережено лише в приватних файлах, не у Git.
- Налаштовано LaunchAgent com.stashnidyk.codex-omniroute (RunAtLoad/KeepAlive, loopback20128), команду ~/.local/bin/codex-free з перевіркою готовності й легшим набором допоміжних інструментів. Початковий race запусків виправлено.
- Combo codex-free: Gemini Flash-Lite → Groq GPT-OSS120B, restricted endpoint key. Claude/OpenRouter/платний резерв не додані.

## Докази та межі

1. Реальний Codex CLI-сеанс через Gemini прочитав sum.mjs інструментом, замінив віднімання на додавання й виконав Node assertions для 2+3 і -2+3. Повторний CLI-сеанс прочитав результат. Це запити зовнішнього провайдера, а не рідна квота Codex.
2. Перші fallback тести з повнішим контекстом виявили Groq413: ліміт8000TPM, запит11334/10348/8123. Не позначали їх успішними.
3. Після зменшення допоміжного контексту короткий Codex-запит пройшов: FALLBACK_OK, 6826tokens, Groq success, 1fallback, HTTP200. Тимчасовий перший target із нульовою квотою відновлено на Flash-Lite. Повний coding workflow під Groq не перевірений; довгий контекст і всі вичерпані квоти залишаються обмеженнями.
4. Поточний desktop-чат і його вбудовані агенти не перенесені автоматично. Потрібне перечитування конфігурації новим сеансом; GUI-вибір провайдера ще не перевірено. Не оголошувати цей чат безлімітним.

Локальні raw logs та тестові файли поза Git. Інструкція: [налаштування](../omniroute-setup.md). Оплата, billing та зовнішні акаунти не змінювалися.
