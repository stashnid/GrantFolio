# Звіти й робота агентів

Ці файли переносять робочий контекст між учасниками й ШІ. Поточний стан читаємо з [STATUS](../STATUS.md), прийняті рішення — з [DECISIONS](../DECISIONS.md). Звіти містять внесок, хід перевірок, розбіжності й наступні дії; це не автоматична синхронізація пам'яті чатів.

Попередні звіти в [planning](../planning/README.md) і старі плани в [archive](../archive/README.md) є історією. Майбутня задача використовує [шаблон](TEMPLATE.md); короткий запис прогресу потрібний і до завершення, щоб незакінчену роботу можна було підхопити.
