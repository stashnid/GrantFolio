# Оформлення PDF та видалення TXT

- Агент Codex. Дата 17.11.2026. Гілка `codex/official-pdf-export`, база — свіжий `origin/main` (`fe378fe`).
- Мета — зробити матеріали для PDF офіційнішими й змістовнішими та залишити PDF єдиним форматом експорту.
- Власні шляхи: `frontend/src/Cases.tsx`, `frontend/src/style.css`, `backend/src/cases.ts`, видалений `backend/src/draft-export.ts`, тести, STATUS, WORKLOG і цей звіт.

PDF — це оформлена для друку робоча чернетка. Додані метадані проєкту, нумеровані розділи, структурований кошторис, дата й версія, інструкції та перевірені джерела програми. Позначка пояснює, що документ не є офіційною формою. Кнопка відкриває друк браузера, де користувач обирає «Зберегти як PDF».

Прибрано TXT-кнопку, frontend-запит, приватний API маршрут, генератор TXT та застарілі перевірки цього формату. Інші матеріали проєкту й PDF не зберігаються автоматично окремим файлом.

Перевірено `npm run build` і `git diff --check`. Тести й браузерний PDF preview не запускалися. У встановленому gstack є router та design review, але немає QA skill, зазначеного в проєктній інструкції.
