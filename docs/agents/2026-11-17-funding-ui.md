## Зміни

Каталог за замовчуванням показує всі sourced записи, включно із завершеними конкурсами, програмами та новими знахідками. Додано напрями, типи фінансування й окремий фільтр підтверджених відкритих наборів. Пошук по всьому каталогу працює незалежно від active-only recommendation engine, який залишено для пояснення актуальних збігів.

Картки й деталі показують тип коштів, програму/конкурс, статус, умови повернення та участь українського бізнесу. Підготовка заявки вимагає доступності за isGrantAvailable, завантаженого підтвердженого запису, reviewStatus != needs-review та programKind != program. Для невідомих і завершених програм доступне офіційне джерело. Дата з точністю до дня не перетворюється на вигаданий час дедлайну. Не обіцяємо коштів без зобов’язань.

Збережено існуючий смарагдовий стиль, hash navigation, повернення фокуса до картки. Фільтри мають видимі label, checkbox, keyboard focus; мобільні поля переходять в одну колонку, кнопки мають мінімум 44px. Застосовано ECC frontend-patterns і targeted UI/UX label/keyboard guidance.
