# Конфігурація AI — етап 1, 19.11.2026

Гілка `codex/master-ai-config`, база `3739621`. Виконавець: делегований агент Terra. Власні файли: `backend/src/ai/`, `backend/src/gemini.ts`, `backend/src/feedback-ai.ts`, `backend/src/smart-grant-monitor.ts`, `.env.example`, тести `ai-config.test.ts`, `gemini.test.ts`, цей звіт.

Модель живої консультації змінена з `gemini-3.5-flash-lite` на `gemini-3.5-flash`; `GEMINI_PRO_MODEL` за відсутності використовує chat. Utility окремо використовує lite, embedding — `gemini-embedding-001`. Старий `GEMINI_MODEL` стосується лише utility і не знижує модель чату. Ідентифікатори валідовано перед формуванням URL, lite заборонено для chat/pro. Збережено прямий API, Vertex EU, bearer/API key та AbortSignal. Третій необов’язковий аргумент `configuredGeminiResponder` задає `chat`, `pro` або `utility`; існуючі виклики залишаються chat. Feedback і monitor використовують utility. `geminiEndpoint` формує URL без секретів; токен як і раніше отримує адаптер.

Системний промпт перенесено у `backend/src/ai/prompts/assistantSystemPrompt.ts`; містить текст зі специфікації та пріоритетні обмеження щодо достовірності, приватності й безпеки. Інструкції інструментів не означають, що вони вже реалізовані: наявний адаптер явно повідомляє моделі, що інструменти недоступні. Додаткове серверне налаштування не має змінювати ці обмеження. Це промптовий захист, не гарантія поведінки моделі.

Перевірки: typecheck, 27 тестів адаптера/конфігурації/якості, 28 тестів монітора, `git diff --check` пройшли. Три застарілі твердження тестів про lite для чату оновлено; перевірки Vertex, помилок та конфіденційності збережені. Живих API-викликів, платних дій, інтеграційних DB-тестів і deploy не було.
