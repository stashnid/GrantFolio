Міграція 026 додає окрему таблицю, а повторюваний запис виконує CLI після міграції. Оновлення чотирьох записів атомарне. Збережений числовий кеш допускається лише за хешем точного тексту відповідного playbook. Дані PostgreSQL не підміняють перевірений текст застосунку. Міграція не змінює наявні таблиці, тому попередній застосунок може ігнорувати нову таблицю. Не видаляйте її під час відкочування коду. Синхронізація не викликає зовнішню модель й не генерує embeddings.

```sh
npm run migrate
node --env-file-if-exists=.env --import tsx backend/src/playbooks/cli.ts
node --import tsx --test backend/test/playbooks.test.ts
```

Встановлений `TEST_DATABASE_URL` локальної тестової БД вмикає додаткову PostgreSQL-перевірку. Вона використовує окрему схему в транзакції з відкочуванням.
