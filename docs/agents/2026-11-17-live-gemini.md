# Gemini на live-сайті GrantFolio

- Агент: Codex Sol. Гілка: `codex/enable-live-gemini`, актуальний base `197b46f` з перевіреного `origin/main`.
- Власні файли: адаптер Gemini, його тест, інструкція розгортання, цей звіт, STATUS і WORKLOG.
- Користувач погодив місячний поріг $40 для Gemini, попросив використати Welcome credit та оновити live-сайт із main.

Gemini Developer API з окремим серверним ключем повернув HTTP 402 через вичерпану передплату. Перший ключ потрапив у службовий вивід CLI. Ключ відкликано, його версію секрету знищено, Cloud Run отримав окрему версію. Welcome credit Google Cloud не покриває Developer API.

Vertex AI EU повернув `STOP` із `gemini-3.5-flash-lite` на один синтетичний запит від оператора. Окремий поріг $40/місяць підтверджено для цього сервісу. Дати закриття первинного trial і початку кредиту після переходу на платний план вказують на перехід до зміни правил 16.11.2026. Фактичне застосування кредиту до тестового SKU ще не підтверджено в Cloud Billing Reports.

Адаптер у цій гілці підтримує Vertex AI через службову ідентичність Cloud Run. Typecheck і 10 цільових тестів пройшли, зокрема перевірка EU endpoint і заголовка з токеном. Автоматична перевірка заблокувала надання `aiplatform.endpoints.predict` для `grantfolio-runtime` без конкретного дозволу користувача. Після дозволу надати це право, перевірити реальний запит від службової ідентичності та розгорнути затверджений код. Повний live-запит асистента ще не підтверджено.
