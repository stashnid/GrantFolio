## Пріоритет і виправлення

1. **P0, неправильний статус прийому.** Календар Мінекономіки й сторінка Дії показували різні дати «Власної справи». Календарний етап уважається відкритим лише за збігу чинного терміну сторінки послуги. Призупинення має пріоритет. Відкритий статус зі старого кешу без доказу звірки знецінюється. Для незареєстрованого бізнесу BLOOM не підставляється як рекомендація. Якщо людина прямо запитує про BLOOM, пояснюємо обмеження. Дайджест використовує збіги зі сферою й потребою, без довільних рекомендацій і вигаданих відсотків.
2. **P0, непідтверджені факти та ризик перезапису.** Чат повертає пропозиції, без запису в профіль. У профілі пропозиції переносяться лише в порожні поля форми. Запис виконується через наявне версійоване збереження. Старий окремий API синхронізації перевіряє ревізію перед записом.
3. **P0, некоректна фінансова чернетка.** Невідомі суми лишаються порожніми. Масове заповнення нулями потребує явного підтвердження. Локальна копія у вкладці відновлюється за збігу версій проєкту, анкети та плану. Розбіжність версій залишає копію для перегляду, без застосування змін до новішого стану. Компонент фінплану прив’язано до власника і проєкту.
4. **P1, перехід до підготовки й повнота експорту.** Для «Власної справи» й саду доступна робоча анкета під час очікування прийому. Чат чітко позначає такий шлях і передає опис потреби. Інші програми мають картки умов і джерела. TXT включає відповіді анкети та кошторис зі збереженого знімка. Робоча фінансова пара XLSX/PDF містить прогноз однієї збереженої версії.

## Перевірки й передача

- `npm run migrate` у відокремленій тестовій БД, `npm run typecheck`, `npm run build`, `git diff --check` і `LIBREOFFICE_TEST=1 npm test` пройшли. 131/131 тести включають Firebase Emulator, PostgreSQL, ізоляцію двох власників, конфлікти версій, зміну статусу прийому і конвертацію PDF з XLSX.
- Chromium 1440×900: реєстрація через форму, кейс незареєстрованої львівської кав’ярні, пояснення без хибного збігу, перенесення потреби, заповнені матеріали й анкета, кошторис 150 000,37 грн. Перевірено вміст завантаженого TXT і отримано ZIP робочих XLSX/PDF. Кнопка переходу веде до Дії.
- Chromium 390×844: повторне відкриття збереженої справи після перезавантаження, відновлення не збереженого у БД значення 25,37 грн у правильній версії, фокус поля, відсутність горизонтального переповнення й блокування фінансового експорту до збереження. Помилок консолі не було. Це емуляція мобільного viewport.
- Публічна головна сторінка й `/api/health` відповіли 200 через HTTPS. Попереднє розгортання описує реєстрацію та поштовий код. Нову гілку на публічному домені не перевіряли. Генерацію живою моделлю в цій роботі не запускали.
- Відновлено доступний контекст шести пов’язаних чатів Codex, включно з сімома сторінками історії головного чату розгортання, та командних передач у Git. Узгоджено пріоритет офіційних форм, розмежування локальної й публічної версій і межі доступу.
