## Рішення й докази

Кнопка входу отримала стилізацію у вигляді білої картки з офіційними кольорами Google, станами hover/active/disabled та видимим фокусом. SVG вбудований, сторонній запит картинки не додається.

Для щойно зареєстрованого акаунта парольний Firebase sign-in вже визначає, що пошта потребує коду. Тому за прапорцем автоматичної відправки UI переходить просто до коду й надсилає його без попереднього GET `/api/auth/email-code/status`. Іншим входам перевірка статусу збережена.

Код AI-підбору вже читає збережений профіль власника, прибирає контактне ім’я, телефон та сайт і передає решту полів як `businessProfile` разом із пошуковим запитом та програмами. Код Gemini adapter додає цей профіль у запит моделі. Поточна production ревізія не має `GEMINI_API_KEY`, отже живий Gemini-підбір наразі вимкнений. API ключ або оплачувані виклики не додавалися.

П'ять мілісекунд не є досяжним SLA для Firebase реєстрації, поштової доставки і підтвердження коду, що проходять через кілька мережевих сервісів. Зміна прибирає один попередній мережевий запит із потоку нової реєстрації. Час до доставки листа окремо не вимірювався.
